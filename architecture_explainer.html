Chess Tutor Architecture

The app works because the model is only the narrator. The board, legal moves, evaluations, and concrete facts come from deterministic tools.

1. Load game
2. Track board
3. Tool call
4. Engine facts
5. Return facts
6. Explain why
Step 1

Load the game

A PGN enters through tutor.py. python-chess parses it, then SessionState stores every real move and starts the current board at the opening position.

Files in the loop

PGN: the user game being reviewed.
session.py: board position, mainline, branches, cache.
tools.py: controlled API the model can call.
engine.py and features.py: Stockfish judgment plus factual board features.
tutor.py: Gemini adapter and manual tool loop.
Answer: Gemini explains only what the tools returned.
